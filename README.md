# Анализ лояльности пользователей Яндекс Афиши

Проект выполняет исследовательский анализ данных для выявления факторов,
влияющих на повторные покупки пользователей Яндекс Афиши.

## Содержание
- `notebooks/30a84906-9dbe-4a93-940c-1c9ebff1567f.ipynb` — основной ноутбук с анализом
- `requirements.txt` — зависимости проекта
- `.gitignore` — исключения для репозитория

## Запуск
1. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
2. Создайте файл `.env` в корне проекта со следующими переменными:
   ```
   DB_HOST=...
   DB_NAME=...
   DB_PORT=...
   DB_USER=...
   DB_PASSWORD=...
   ```
3. Откройте ноутбук и выполните все ячейки.

## Примечания
- Данные по курсу тенге автоматически загружаются из внешнего CSV.
- `.env` не коммитится и хранит чувствительные данные.
